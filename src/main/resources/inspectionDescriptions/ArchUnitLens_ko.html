ArchUnit Lens가 정적으로 해석할 수 있는 보수적 ArchUnit rule subset의 위반을 보고합니다. 최종 기준은 계속 ArchUnit 테스트이며, 이 inspection은 에디터에서 제공하는 조기 피드백입니다.

canonical 지원 계약은 docs/rule-support-matrix.md에 있습니다. 현재 live warning family는 explicit import와 resolved Java reference 기반 package dependency ban, class suffix rule, forbidden annotation, annotation exclusivity, annotation/meta-annotation/package/suffix/interface/enum/record/final modifier fact 기반 typed class convention, QueryMapper 형태 interface rule, literal class/method meta-annotation rule, private constructor/static method/resolved exact raw return type 기반 positive method/constructor declaration convention, 정적으로 판정 가능한 negative noFields()/noMethods() annotation/name/modifier/declaring-class rule입니다. 부정 polarity는 지원되는 전체 condition tree에 한 번만 적용됩니다. exact noClasses() field access, signature-aware method call, constructor access도 지원합니다. 모든 leaf가 exact하고 정적으로 지원·resolve될 때만 class predicate and()/or(), condition andShould(), code-access의 left-associative andShould()/orShould()를 live warning으로 평가합니다.

meta-annotation fact는 각 annotation 단계에서 CLASS/RUNTIME retention(기본 CLASS)을 따릅니다. SOURCE retention 경로는 meta-annotation 일치나 annotation 제거 fix를 만들지 않습니다. 미해결 경로나 retention 값은 일치를 증명하지 못하지만, 별도의 확인된 retained 경로가 일치하면 warning을 만들 수 있습니다.

소스의 non-static member constructor는 바로 바깥 클래스 타입을 첫 JVM parameter로 포함합니다. compiled inner constructor의 시그니처를 확정할 수 없으면 warning을 만들지 않습니다. Package scope는 literal/Java 상수 @AnalyzeClasses(packages = ...)와 해석 가능한 packagesOf class literal의 package를 합칩니다. bare annotation이나 빈 배열은 annotation을 붙인 클래스의 package를 사용합니다. 해석할 수 없는 범위 원소, 비어 있지 않은 location provider/import option/개별 클래스, 전체 classpath import가 있으면 rule 전체를 metadata로만 보존합니다. 프로젝트 provider와 option은 실행하지 않습니다.

지원하는 subject entry point는 실제 ArchRuleDefinition의 유일하고 유효한 static 메서드 선언으로 resolve되어야 합니다. 같은 이름의 project helper와 소유권이 미해결이거나 모호한 root는 metadata-only로 유지합니다. 컴파일 시 인라인되는 primitive/String 상수 읽기는 제외하며 비상수 읽기와 명시적인 쓰기는 계속 검출합니다. 선언 initializer의 암시적 쓰기는 PSI에서 별도로 생성하지 않습니다. 지원하지 않거나 custom/helper 기반이거나 의미가 불확실한 rule은 가능한 경우 Rule Overview metadata로 보존하지만 warning은 만들지 않습니다. 지원하지 않는 field/method/constructor declaration, literal schema가 아닌 method/constructor access, access predicate, method reference, unsupported sibling은 metadata-only로 유지합니다. 지원/미지원 rule, scope, reason, unsupported reason, scan metrics는 ArchUnit Lens tool window에서 확인할 수 있습니다.
